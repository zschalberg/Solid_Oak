# pokefirered-expansion
To set up the repository, see [INSTALL.md](https://github.com/rh-hideout/pokeemerald-expansion/blob/upcoming/INSTALL.md).
## Disclaimer
This repository is not getting updated anymore outside of bugfixes. Use [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion)'s FRLG build instead, if you want new features.

## Branches
- Solid-Oak - Main development branch for Pokémon Solid Oak. Contains custom features, level scaling, size mechanics, seen/caught tracking expansion, quest logs, and starter cabin spawning. See [docs/features.md](docs/features.md) for details.
- master - pokefirered with expansion features
- no-ql-and-hs - master without quest log and help system
- dppt-hgss-music - master with HQ mixer and DPPt/HGSS music
